I've been working a side project that uses the Tumblr public API quite a lot and I didn't really care for any of the existing libraries out there, so being a big-headed pompous ass, of course I wrote my own.
There aren't any authenticated calls yet, so you can only get the public data like posts, avatar and blog info.

The code is on [Github](https://github.com/edvanbeinum/humblr) and I put together some quick docs at <http://humblr.edvanbeinum.com>
