I've been working on a theme for [PHPStorm](http://www.jetbrains.com/phpstorm/) which is a port of the Monokai colour scheme from [Sublime Text 2](http://www.sublimetext.com/2). It should cover PHP, HTML, CSS, Javascript, XML and ini formats. 

You can download the theme [here](http://edvanbeinum.bitbucket.org/monokai-sublime.jar). 

![Monokai ported to PHPStorm](/user/themes/veebs/images/monokai-dark-screenshot.png)

To install, save the .jar file locally then select File > Import Settings in PHPStorm. This should only add a colour scheme and not affect any other settings in the IDE.

There is an existing port Monokai by [Haza](http://phpstorm.haza.fr/?p=17)  The colours there looked a bit washed out on my monitor, but its certainly worth a look.
