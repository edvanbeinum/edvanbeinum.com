Listening to the latest episode of the [Ruby Rogues](http://rubyrogues.com/051-rr-getting-started-with-open-source/) podcast (I don't care if you aren't a Ruby dev, go subscribe immediately - it is fantastic) I loved what [David Brady](http://twitter.com/dbrady) said about trying to contribute to OS once a day and the [Calendar About Nothing](http://calendaraboutnothing.com/).

The Calendar About Nothing for those that haven't heard of it, tracks each day that you push code to a public Github repo. It is based on something Jerry Seinfeld said about how he manages to write something everyday which became a bit of a meme on the internet a few years ago. You can read more about it on [lifehacker](http://lifehacker.com/281626/jerry-seinfelds-productivity-secret).

Off the back of that, I'm declaring __May 2012 to be my month of daily pushes to Github__.  

Of course, it is going to be difficult to balance my paid (and private) work with public contributions so some days it might just been passing a few more Ruby Koans. But still, I'm striving for a daily output of something useful.

[You can track my progress here](http://calendaraboutnothing.com/~edvanbeinum)
